# Planificación en 12 sprints

| Sprint | Entregable |
|---|---|
| 1 | Análisis y documentación: planteamiento, justificación, hipótesis y objetivos |
| 2 | Investigación técnica: comparar LBPH vs embeddings, definir arquitectura y stack |
| 3 | Diseño de base de datos: tablas alumnos, tutores, bitácora y diagrama entidad-relación |
| 4 | Esqueleto del backend: estructura PHP MVC y conexión a MySQL |
| 5 | Módulo de registro (enrollment): captura de rostro y alta de tutores |
| 6 | Módulo de verificación: comparar el rostro capturado contra los tutores autorizados |
| 7 | Integración de cámara/hardware: webcam, DroidCam o ESP32-CAM en tiempo real |
| 8 | Notificaciones: pantalla del salón y protocolo de respaldo (PIN/validación manual) |
| 9 | Bitácora y panel administrativo: reportes e historial por alumno |
| 10 | Pruebas de precisión: luz, lentes, cubrebocas; falsos positivos/negativos y tiempos |
| 11 | Pruebas de usabilidad y ajustes: umbrales de confianza y corrección de errores |
| 12 | Documentación final y cierre: manual de usuario, documentación técnica, presentación |
